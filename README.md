# Watermark Stamp

เว็บสำหรับประทับลายน้ำ (Watermark) ลงรูปภาพหลายไฟล์พร้อมกันแบบฟรี โดยทำงานทั้งหมดในเบราว์เซอร์

## เปิดใช้งานเว็บไซต์

- https://porsurapan.github.io/WatermarkStamp/

## เนื้อหาโดยสรุปของเว็บ

- ประทับลายน้ำลงรูปภาพได้หลายไฟล์ในครั้งเดียว
- รองรับไฟล์ภาพหลัก เช่น JPG, PNG และ WebP
- ทำงานบนเบราว์เซอร์ ไม่ต้องอัปโหลดรูปขึ้นเซิร์ฟเวอร์
- มีตัวเลือกปรับข้อความ รูปแบบ ขนาด สี ความโปร่งใส และตำแหน่งของลายน้ำ
